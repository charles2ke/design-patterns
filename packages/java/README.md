
# design-patterns-catalog

Install:

```xml
<dependency>
  <groupId>com.designpatterns</groupId>
  <artifactId>design-patterns-catalog</artifactId>
  <version>0.1.0</version>
</dependency>
```

Usage:

```java
var behavioral = PatternFilter.filterPatterns(Patterns.ALL, "undo", "Behavioral");
var counts = PatternFilter.countByCategory(Patterns.ALL);
```
